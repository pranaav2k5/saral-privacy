# Security policy

Do not open public issues for security problems. Report them privately to the repository owner (`pranaav2k5`) through GitHub private vulnerability reporting or direct message, with steps to reproduce and the affected component.

Secrets, keys, and personal data must never be committed. If you find one in the repository or its history, report it the same way so it can be rotated and removed.

This repository is under active development and has no production deployment yet.
